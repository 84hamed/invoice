# Invoice Project - AI Ready

این پروژه یک سیستم مدیریت و تولید فاکتور است که برای **دسترسی سریع و تحلیل توسط هوش مصنوعی (AI)** آماده شده است.

## شاخه فعلی
`Fast-tracking-to-files-via-AI`

## امکانات پروژه
- مدیریت کالاها، خدمات، قیمت‌ها و محاسبه مجموع پرداختی
- ذخیره و بارگذاری فاکتورها در LocalStorage و فایل JSON
- بروزرسانی خودکار قیمت‌ها از URL محصولات
- Undo تغییرات و مدیریت خدمات ذخیره‌شده
- چاپ فاکتور و صادرات به Excel و Word

## ساختار فایل‌ها
- `index.html` → رابط کاربری
- `styles.css` → استایل‌ها
- `script.js` → منطق اصلی پروژه
- `script.txt` → نسخه متنی ساده برای AI
- `README.md` → توضیحات پروژه
